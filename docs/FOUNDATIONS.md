## 1. Grid System

Единая колоночная сетка. Значения — из grid-токенов.

| Устройство | Диапазон | Колонки | Container | Max-width | Gutter | Margin |
|---|---|---|---|---|---|---|
| **Mobile** | < 768px | **4** | 100% − margins | — | 16px | 16px |
| **Tablet** | 768–1023px | **8** | 100% − margins | — | 20px | 32px |
| **Laptop** | 1024–1279px | **12** | 100% − margins | 1200px | 24px | 64px |
| **Desktop** | ≥ 1280px | **12** | центрируется | **1200px** | 24px | авто (центр) |

- **Safe area:** на мобильных добавляй `--safe-left/right` к margin, `--safe-bottom`
  к нижним панелям (iOS notch/home-indicator).
- **Alignment:** контент прижат к колонкам, не к пикселям; текстовые блоки — по левому краю.
- **Responsive behavior:** 12 → 8 → 4 колонки; элемент, занимавший 4 из 12 на десктопе
  (⅓), на планшете занимает 4 из 8 (½), на мобиле — 4 из 4 (полную ширину).

**Почему такие значения:** 12 делится на 2/3/4/6 — максимум вариантов раскладки без дробей.
`max-width: 1200px` — длина строки остаётся читаемой (~65 символов при 16px), контент не
расплывается на широких экранах (закон читаемости). Margin 64px на десктопе даёт «воздух
дорогого продукта» (Philosophy P10); 16px на мобиле — максимум полезной ширины.

- **Best practice:** контент всегда внутри `--container-max` (1200px); фоны/hero — full-bleed,
  но их содержимое — в контейнере.
- ❌ Контент на всю ширину 4K-монитора; строки по 140 символов.
- ✅ `max-width: 1200px; margin-inline: auto;` + full-bleed фон.
- 👩‍💻 `grid grid-cols-4 md:grid-cols-8 lg:grid-cols-12 gap-4 lg:gap-6`; обёртка `max-w-content mx-auto px-4 lg:px-16`.
- 🎨 Figma: layout grid 12 col, gutter 24, margin 64, max 1200 — сохрани как **Grid Style**.

## 2. Breakpoint Strategy

Из `--breakpoint-*`. Совпадают с Tailwind (sm–2xl), плюс xs и 3xl.

| BP | ≥ px | Устройства | Что делает |
|---|---|---|---|
| **xs** | 480 | Крупные телефоны | Тонкая правка плотности; 1 колонка |
| **sm** | 640 | Ландшафт-телефоны | 1–2 колонки, крупнее тап-зоны |
| **md** | 768 | Планшеты | Сетка 8 колонок; сайдбар всё ещё скрыт |
| **lg** | 1024 | Ноутбуки | **Сайдбар появляется**; сетка 12; многоколоночные раскладки |
| **xl** | 1280 | Десктопы | Контейнер центрируется, max 1200 |
| **2xl** | 1536 | Большие мониторы | Больше воздуха по бокам, контент не растёт |
| **3xl** | 1920 | Wide / ТВ | Только поля растут, контент фиксирован 1200 |

**Правила переходов:**
- **Mobile-first:** базовые стили — без префикса; расширяй вверх (`md:`, `lg:`).
- **lg — главный слом:** до него навигация в бургере/боттом-баре, после — постоянный сайдбар.
- **Контент не масштабируется бесконечно:** после `xl` растут поля, не текст (Philosophy P10).
- **Один компонент — минимум переломов:** карточка меняет раскладку максимум в 2 брейкпоинтах.

- ❌ Кастомные брейкпоинты вроде `@media (max-width: 913px)` под конкретный экран.
- ✅ Только 7 системных брейкпоинтов; `hidden lg:block` для сайдбара.
- 👩‍💻 Только up-варианты Tailwind (`md:`), избегай `max-*` кроме редких случаев.
- 🎨 Figma: 4 фрейма-эталона — 375 / 768 / 1024 / 1440.

## 3. Layout Principles

- **Вертикальный ритм:** расстояния кратны 8px (`--space-*`). Между секциями страницы —
  `--space-16…24` (64–96px), внутри секции — `--space-6…10` (24–40px).
- **Горизонтальный ритм:** gutters из сетки; между инлайн-элементами — `--space-2…3`.
- **Композиция:** один главный вопрос на экран (Philosophy P1); F/Z-паттерн чтения —
  важное слева-сверху.
- **Визуальный баланс:** асимметрия допустима, но оптически уравновешена; «тяжёлые»
  элементы (изображения, CTA) уравновешивают пустоту.
- **Белое пространство:** активный инструмент фокуса; вокруг главного действия — воздух.
- **Плотность:** заслуживается ясностью (Philosophy P8) — дашборды плотные, онбординг просторный.
- **Выравнивание:** всё выровнено по сетке 8px и по колонкам; текст — по левому краю (не по центру для длинных блоков).
- **Вложенность:** максимум 3 уровня визуальной вложенности (страница → секция → карточка → элемент); глубже — переосмысли структуру.

- ❌ Центрированные абзацы на 3 строки; случайные отступы 13px, 27px.
- ✅ Левое выравнивание, отступы 16/24/32, ≤ 3 уровня вложенности.
- 👩‍💻 Раскладка через `flex`/`grid` + `gap`, не через margin-хаки.
- 🎨 Всё на сетке 8px; включи «pixel grid» и baseline-проверку.

## 4. Auto Layout (Figma)

Стандарты, чтобы компоненты масштабировались автоматически.

- **Направление:** вертикальное для секций/форм, горизонтальное для тулбаров/строк.
- **Spacing (gap):** только из `--space-*` (8/12/16/24…). Никаких ручных отступов.
- **Padding:** карточки — 16–24; кнопки — 12×20 (h 44); панели — 24–32.
- **Hugging:** кнопки, чипы, бейджи — «hug contents» (растут по контенту).
- **Fill container:** инпуты, строки списков, ячейки таблиц — «fill» по ширине.
- **Fixed size:** аватары, иконки, тумблеры — фиксированный размер.
- **Min/Max:** контейнеры — `min-width: 0` (чтобы flex-дети сжимались), контент — `max-width: 1200`.
- **Constraints:** сайдбар — left+top/bottom; контент — left+right (растягивается); модалка — center.

**Как строить масштабируемый компонент:** Auto Layout + fill/hug осознанно + токены spacing +
`min-width: 0` на текстовых контейнерах (иначе длинный текст ломает раскладку).

- ❌ Абсолютное позиционирование, фиксированная ширина карточки 320px везде.
- ✅ Auto Layout, fill-container, `min-w-0` + `truncate` на длинных строках.
- 👩‍💻 `min-w-0` на flex-детях с текстом; `flex-1` = fill, `shrink-0` = fixed.
- 🎨 Component Properties: variant (`size`, `state`), boolean (`icon`), instance-swap (иконка).

## 5. Responsive Design

**Mobile First:** проектируй с 375px, расширяй вверх.

| Слой | Что меняется | Что неизменно |
|---|---|---|
| **Mobile** (<768) | 1 колонка, сайдбар→бургер, таблицы→карточки, боттом-CTA | Токены, иерархия, бренд |
| **Tablet** (768–1023) | 2 колонки, сетка 8, крупнее тап-зоны | Логика экрана |
| **Desktop** (≥1024) | Сайдбар, 12 колонок, многоколоночные раскладки | Токены, компоненты |
| **Ultra-wide** (≥1536) | Растут только поля, контент центрирован 1200 | Ширина контента |

- **Блоки:** перестраиваются сверху-вниз (stack) на мобиле; в ряд — на десктопе.
- **Карточки:** grid из 3 → 2 → 1 колонки; внутри карточка stack на мобиле.
- **Таблицы:** на мобиле → карточки «label: value» или горизонтальный скролл в
  `overflow-x: auto` контейнере (страница НЕ скроллится вбок).
- **Формы:** многоколоночные поля → одна колонка на мобиле; label над полем всегда.

- ❌ Таблица на 8 колонок с горизонтальным скроллом всей страницы на телефоне.
- ✅ Таблица → карточки на мобиле; или скролл внутри своего контейнера.
- 👩‍💻 `overflow-x-auto` на обёртке таблицы; `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`.
- 🎨 Проектируй 3 состояния каждого блока: mobile / tablet / desktop.

## 6. Icon System

- **Библиотека:** **lucide** (одна, единая). Не смешивать наборы.
- **Размеры:** `--icon-xs 12 · sm 14 · md 16 · lg 20 · xl 24 · 2xl 32`. Инлайн с текстом — 14–16.
- **Толщина линий:** `--icon-stroke 2px` (по умолчанию), `1.5px` для крупных (≥24).
- **Стиль:** outline, единый вес, скругления `--icon-radius 2px` (совпадает с lucide).
- **Цвета:** `--color-icon-*` (primary/secondary/disabled/interactive/brand). Иконка наследует цвет текста рядом.
- **Использование:** иконка **усиливает** текст, редко заменяет; в кнопке — 14–16px рядом с лейблом.
- **Запрещено:** смешивать filled/outline; цветные многоцветные иконки (кроме логотипов брендов OAuth); иконка без подписи как единственный носитель смысла (a11y); произвольные размеры вне шкалы.
- **Выбор иконки:** метафора должна быть однозначной и общепринятой; при сомнении — добавь текст.

- ❌ Font Awesome + lucide вместе; иконка-корзина 19px.
- ✅ Только lucide, `size={16}`, `strokeWidth={2}`, цвет = `currentColor`.
- 👩‍💻 `<Trash2 size={16} />`, иконочные кнопки — с `aria-label`.
- 🎨 Иконки как компоненты с instance-swap; библиотека = одна страница в Figma.

## 7. Image System

- **Фотографии:** приглушённые, не кричащие; тёмная обработка под фон `#05060A`.
- **Иллюстрации:** линейные/геометрические, в акцентной палитре (индиго/violet); не мультяшные.
- **AI-изображения:** помечаются как сгенерированные (Philosophy — честность); не выдаём за фото.
- **Обложки/превью:** соотношение 16:9 (широкие) или 4:3 (карточки); `object-fit: cover`.
- **Качество:** 2× для retina; форматы AVIF/WebP; `next/image` для оптимизации и lazy-load.
- **Пропорции:** фиксированные `aspect-ratio` — контейнер знает высоту до загрузки (нет CLS).
- **Оптимизация:** `next/image` с `sizes`; вес карточной картинки ≤ 100КБ; блюр-плейсхолдер.

- ❌ `<img>` без размеров (сдвиг layout); PNG 2МБ на карточке.
- ✅ `next/image` с `width/height`/`fill` + `aspect-ratio` + placeholder.
- 👩‍💻 `next/image`, `remotePatterns` в `next.config`, `sizes` под сетку.
- 🎨 Задавай `aspect-ratio` контейнерам; экспорт 2×, WebP/AVIF.

## 8. Avatar System

- **Размеры:** xs 24 · sm 32 · md 40 · lg 48 · xl 64px (кратны 8).
- **Формы:** круг (люди), squircle `--radius-chip` 10px (агенты/бренды).
- **Статусы:** точка-индикатор 8–10px в правом-нижнем углу (`--color-success` online / muted offline), с обводкой цвета фона.
- **Группы:** стек с перекрытием −8px, обводка фоном; «+N» чипом при переполнении (как на welcome-экране: SR MC ET JW AP +15).
- **Fallback:** инициалы на бренд-градиенте (первая буква имени) — если нет фото.
- **Загрузка:** клиентский ресайз до 256×256, круглый превью, skeleton при загрузке (см. AvatarUpload в профиле).

- ❌ Аватары разных форм в одном списке; растянутое неквадратное фото.
- ✅ Единая форма/размер в контексте; `object-fit: cover`; fallback-инициалы.
- 👩‍💻 `<img>` в круглом контейнере `overflow-hidden` + fallback-компонент.
- 🎨 Avatar как компонент: props `size`, `status`, `shape`, boolean `hasImage`.

## 9. Spacing Rules

Вертикальный ритм на сетке 8px. Из `--space-*`.

| Между чем | Токен | px |
|---|---|---|
| Секциями страницы | `--space-16…24` | 64–96 |
| Заголовком и контентом секции | `--space-6…8` | 24–32 |
| Карточками (grid gap) | `--space-4…6` | 16–24 |
| Полями формы | `--space-4` | 16 |
| Кнопками в ряду | `--space-3` | 12 |
| Абзацами текста | `--space-3…4` | 12–16 |
| Иконкой и текстом | `--space-2` | 8 |
| Меткой и значением (инлайн) | `--space-1…2` | 4–8 |

**Правило вертикального ритма:** чем крупнее логический разрыв — тем больше отступ.
Внутригрупповые расстояния всегда меньше межгрупповых (закон близости).

- ❌ Одинаковый отступ 16px и между полями, и между секциями (нет иерархии).
- ✅ 16 внутри группы, 64 между секциями — разрыв читается.
- 👩‍💻 `gap-*` / `space-y-*` из шкалы; ноль «магических» px.
- 🎨 Auto Layout gap только из spacing-переменных.

## 10. Elevation

6 уровней глубины (`--elevation-0…5`), матовые тени, **без цветного glow**.

| Уровень | Что | Тень |
|---|---|---|
| **0** | Фон, flush-элементы | none |
| **1** | Карточки в покое | `--elevation-1` |
| **2** | Карточки на hover, поднятые блоки | `--elevation-2` |
| **3** | Dropdown, popover, tooltip-крупные | `--elevation-3` |
| **4** | Плавающие панели, drawer | `--elevation-4` |
| **5** | Модалки, command palette | `--elevation-5` |

- **На фоне:** страница, секции (уровень 0).
- **Поверх:** dropdown/popover (3), модалка (5) + `--color-overlay` скрим.
- **Тени:** только матовые нейтральные (`rgba(0,0,0,…)` + тонкий inset-хайлайт).
- **Blur:** для стеклянных поверхностей (navbar `--blur-e-xl`, модалка-подложка); не злоупотреблять.

- ❌ Цветная indigo-тень «glow»; двойные тени на вложенных карточках.
- ✅ `shadow-e2` на hover карточки; `shadow-e5` + overlay на модалке.
- 👩‍💻 `shadow-e1…e5`, `--color-overlay` для скрима, `z-*` из шкалы.
- 🎨 Effect Styles: Elevation/1…5; blur как отдельный effect.

## 11. Motion Foundations

Из motion-токенов. Принцип: движение с назначением (Philosophy P11).

- **Когда:** появление контента, переход состояний, hover-feedback, стриминг AI, layout-переходы.
- **Когда запрещено:** декоративные бесконечные loop, вращающийся glow, анимация всего сразу, движение, блокирующее контент.
- **Скорость:** hover/микро `--duration-fast` (150мс); появление `--duration-slow` (400–600); модалка `--duration-normal` (250).
- **Easing:** по умолчанию `--ease-standard` (out-quint); пружина/снап — `--ease-spring`; симметрично — `--ease-in-out`.
- **Последовательность (stagger):** дети появляются с задержкой 60–110мс (fade-up), не все разом.
- **Микроанимации:** тап −1px, hover подъём карточки 2px, пульс live-точки.
- **Загрузка:** skeleton (не спиннер) для контента; стриминг токенов для AI.
- **Обязательно:** ветка `prefers-reduced-motion: reduce` (финальное статичное состояние).

- ❌ Модалка «выезжает» 900мс; бесконечный крутящийся glow-бордер.
- ✅ Fade-up 400мс, stagger 80мс, `ease-standard`; reduced-motion → без анимации.
- 👩‍💻 Framer Motion с `[0.22,1,0.36,1]`; `useReducedMotion()`; `will-change` умеренно.
- 🎨 Прототипы: Smart Animate, easing custom (0.22,1,0.36,1), длительности из шкалы.

## 12. Accessibility (WCAG AA)

- **Кликабельная область:** ≥ **44×44px** (закон Фиттса), даже если иконка визуально меньше.
- **Контраст:** текст ≥ **4.5:1**, крупный/иконки ≥ 3:1. `--color-text-muted` (#4B5563) —
  только декор/meta, не основной текст.
- **Keyboard navigation:** весь функционал с клавиатуры; логичный порядок; Esc закрывает оверлеи.
- **Focus ring:** `:focus-visible` всегда виден (`--shadow-focus`, кольцо индиго); никогда `outline: none` без замены.
- **Tab order:** соответствует визуальному порядку (DOM-порядок = порядок чтения); ловушка фокуса только в модалке (+ возврат фокуса при закрытии).
- **Screen reader:** семантический HTML (`button`/`nav`/`main`, заголовки по уровням); `aria-label` на иконочных кнопках; `aria-live="polite"` для тостов и стриминга AI; декоративные картинки `alt=""`.
- **Не только цвет:** статус = цвет + иконка + текст.

- ❌ `<div onClick>` вместо кнопки; серый текст #4B5563 как body; `outline:none`.
- ✅ `<button aria-label>`, focus-visible кольцо, контраст ≥ 4.5:1.
- 👩‍💻 Тестируй Tab/Shift-Tab/Esc; `axe`/Lighthouse в CI.
- 🎨 Проверяй контраст плагином; помечай tab-order и aria в спеке.

## 13. Content Layout

- **Заголовки:** `text-wrap: balance`, вес 800, tracking −0.02em; отвечают на один вопрос секции.
- **Подзаголовки:** `--color-text-secondary`, под заголовком, поясняют.
- **Абзацы:** `line-height 1.6–1.75`, строка ~65 символов, левое выравнивание.
- **Списки:** маркер выровнен, отступ 8; между пунктами `--space-2`; параллельная грамматика.
- **Таблицы:** `tabular-nums` для цифр, выравнивание чисел вправо, строки ≥ 44px, hover-подсветка, sticky-заголовок при скролле.
- **Код:** `--font-mono`, фон `--color-surface`, `--radius-lg`, горизонтальный скролл внутри блока.
- **AI-ответы:** markdown-рендер, ширина ~65 символов, стриминг по токенам, «reasoning» — вторичным текстом (Philosophy P3).
- **Уведомления/тосты:** иконка + краткий текст + действие; `--color-*-bg/-border`; `aria-live`.

- ❌ Заголовок на всю ширину 1200px; таблица без выравнивания чисел.
- ✅ Заголовок `max-w` + balance; числа `tabular-nums` вправо.
- 👩‍💻 `text-balance` (уже в globals), markdown-санитайз для AI-вывода.

## 14. Empty States

**Структура:** иконка/иллюстрация → заголовок (одна фраза) → пояснение (1–2 строки) → **один** CTA.

- **Изображение:** приглушённая иконка в круге `--color-card` или простая иллюстрация; не крупная и не кричащая.
- **Текст:** объясняет ценность и первый шаг, не «Здесь пусто». Пример: «У вас пока нет passkey. Добавьте, чтобы входить без пароля».
- **CTA:** одно главное действие (primary); вторичное — ссылкой.
- **Рекомендации:** empty-state — возможность, а не ошибка; тон спокойный, приглашающий.

- ❌ Пустой белый экран; «No data».
- ✅ Иконка + «Создайте первый проект» + кнопка «Новый проект».
- 👩‍💻 Empty-state — обязательное состояние каждого списка (наравне с loading/error).
- 🎨 Компонент `EmptyState`: props `icon`, `title`, `description`, `action`.

## 15. Loading States

| Тип | Когда |
|---|---|
| **Skeleton** | Загрузка структурированного контента (списки, карточки, дашборд) — предпочтительно |
| **Spinner** | Короткие действия внутри кнопки/иконки (< 1с ожидания) |
| **Progress** | Известный детерминированный прогресс (загрузка файла, генерация по шагам) |
| **Streaming AI** | AI-ответы — по токенам, с курсором/пульсацией, чёткое «готово» |
| **Placeholder** | Изображения — блюр-плейсхолдер до загрузки |

- **Правило:** воспринимаемая скорость > реальной (Philosophy P6); скелетон повторяет будущую раскладку (нет CLS).
- ❌ Пустой экран на 3 секунды; спиннер вместо скелетона для целой страницы.
- ✅ Skeleton-карточки → контент; стриминг AI по токенам.
- 👩‍💻 Skeleton = те же размеры, что контент; `aria-busy="true"`.
- 🎨 Skeleton-компоненты как варианты реальных карточек (opacity/pulse).

## 16. Error States

Тон — спокойный, с причиной и путём решения (Philosophy P2, P7). Никогда не показывать сырой стек/текст провайдера.

| Источник | Паттерн |
|---|---|
| **Формы** | Inline под полем, после потери фокуса; `--color-input-error`; конкретно («минимум 8 символов»). |
| **API** | Тост/блок с причиной + «Повторить»; не техножаргон. |
| **AI** | «Модель не смогла обработать — переформулируйте»; сырой error провайдера скрыт. |
| **Сеть** | Баннер «Нет соединения», авто-retry, оптимистичный откат. |
| **Сервер (5xx)** | Спокойный full-state «Что-то пошло не так» + «Обновить»; логируется в Sentry. |
| **Авторизация (401/403)** | Редирект на вход с `callbackUrl`; «Войдите, чтобы продолжить». |

- ❌ Красный «FATAL ERROR: PGRST 42P01»; вина на пользователя.
- ✅ «Не удалось сохранить. Проверьте соединение и повторите» + кнопка.
- 👩‍💻 Единый `jsonError()` на бэке (generic-текст), детали — в лог; ErrorBoundary на фронте.
- 🎨 Error-состояние каждого компонента; семантика `--color-error-*`.

## 18. Figma Structure

- **Variables:** импорт [`design/figma-variables.json`](../design/figma-variables.json) — коллекции Primitives/Semantic/Typography/Spacing/Radius/Elevation/Motion/Layout/Icon/State. Компоненты биндятся к **Semantic**, не к Primitives.
- **Styles:** Text Styles (уровни из Typography), Effect Styles (Elevation 1–5, Blur), Grid Styles (12/8/4 из раздела 1).
- **Auto Layout:** по стандартам раздела 4 (gap/padding из spacing-переменных, fill/hug осознанно).
- **Component Properties:** variant (`size`, `state`, `variant`), boolean (`icon`, `loading`), instance-swap (иконка), text (label). Один компонент — все варианты, не копии.
- **Modes:** коллекция Semantic поддерживает режим Dark (дефолт); Light добавляется переопределением Semantic, Primitives не трогаются.

## 19. Ready for Development

- **React / Next.js:** App Router, `"use client"` где нужна интерактивность; серверные компоненты по умолчанию. Все состояния (loading/empty/error/success) — обязательны.
- **Tailwind CSS v4:** токены уже заведены через `@theme` в `tokens.css`. Утилиты: `bg-surface`, `text-ink`, `rounded-card`, `shadow-e2`, `ease-standard`, `max-w-content`. Числовые дефолты Tailwind не тронуты.
- **Компонентный слой:** проект использует **кастомный `src/components/ui/`** (Button/Card/Progress) в стиле, близком к shadcn (`variant`/`size`/`cn`), **но без Radix/cva**. Токены **shadcn-совместимы** (CSS-переменная-конвенция) — если команда решит перейти на shadcn/ui, semantic-токены мапятся на его `--background`/`--foreground`/`--primary` напрямую.
- **Правило:** новый компонент строится только из токенов и Foundations; никаких магических чисел и одноразовых стилей.

- 👩‍💻 Пример кнопки-primary: `h-11 px-5 rounded-btn font-bold text-white bg-[image:var(--btn-primary-bg)] shadow-e2 transition ease-standard duration-fast`.
- 🎨 Спека компонента = ссылка на токены + Auto Layout + Component Properties, а не пиксельные значения.
