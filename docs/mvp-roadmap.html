⚡ Главный принцип: Build Less, Learn Faster

Каждая строчка кода — это риск. Цель MVP не «сделать красиво», а максимально быстро проверить: платят ли люди за AI-совет директоров. Всё, что не приближает к первому платящему пользователю, — откладывается.

✓ Обязательно

Auth, дашборд, AI-чат с 1–3 агентами, история, базовая подписка. Без этого нет продукта.

↻ Отложить

Команды, marketplace, RAG-загрузка документов, интеграции, кастомные модели.

✗ Не делать сейчас

Мобильное приложение, on-prem, SSO/SAML, сложная аналитика, автоматизации.

Реальность проекта: MVP уже почти построен

Vertlix AI — не с нуля. Auth (2FA, passkeys), дашборд, стриминг AI-чата, 20 агентов, генерация стратегий, план-лимиты и безопасность (RLS) уже реализованы и работают. Поэтому этот роадмап — не «построить с нуля», а самый быстрый путь к запуску и первым пользователям: доделать последнюю милю (реальный checkout, Cloudflare, аналитика) и выйти на рынок.

01  MVP Strategy

Кому, какую боль и почему заплатят

Одна аудитория, одна боль, одно ядро ценности. Фокус — не «все предприниматели», а тот, кому AI-совет нужен вчера.

🎯 Target User

Соло-основатель стартапа / владелец МСБ (25–45), у которого нет команды и денег на консультантов, но есть решения с высокой ставкой каждую неделю.

🔥 Main Problem

«Мне не с кем обсудить бизнес-решение на уровне CFO/CMO/CEO. Найм экспертов — дорого и медленно, ChatGPT даёт общий ответ без структуры и роли.»

💎 Core Value Proposition

Виртуальный совет из 20 AI-директоров, который анализирует твой проект и даёт структурированное решение с обоснованием — за минуты, не за $$$.

⚡ Main Feature (одна!)

Задать вопрос профильному директору (CEO/CFO/CMO) о своём проекте и получить экспертный ответ со стримингом + обоснованием. Всё остальное — вокруг этого.

Почему пользователь заплатит за MVP?

Потому что альтернатива дороже: консультант — от $150/час, найм C-level — от $10k/мес, а «бесплатный ChatGPT» не даёт ролевую экспертизу + структуру решения + сохранённую историю проекта. За $19–49/мес основатель получает «совет директоров по требованию».

Гипотеза для проверки: ≥ 3% зарегистрировавшихся конвертируются в платящих в первый месяц.

04  MVP User Flow

Полный путь пользователя

От анонимного посетителя до платящего. Каждый шаг убирает трение и ведёт к «первому результату» как можно быстрее.
1 · VisitorЗаходит на Landing → видит «AI-совет директоров для твоего бизнеса» + один CTA «Начать».
2 · RegisterEmail+пароль или Google/GitHub (1 клик). Минимум полей. Организация создаётся автоматически.
3 · OnboardingНе тур, а первое действие: «Расскажи о проекте» → короткая форма (идея/индустрия/стадия).
4 · Choose AgentВыбирает директора (CEO/CFO/CMO) — или совет целиком.
5 · Ask QuestionЗадаёт бизнес-вопрос о своём проекте.
6 · Receive ResultСтриминг ответа по токенам + обоснование + следующий шаг. «Ага-момент».
7 · Save ResultСохраняет в историю / Vault; может сгенерировать стратегию (6 секций) и отчёт.
8 · UpgradeНа 4-м проекте / лимите отчётов → «Перейти на Pro» (контекстно, не навязчиво).

Ключевая метрика этого флоу: Time-to-Value

Цель — первый полезный AI-ответ менее чем за 5 минут от регистрации. Всё, что удлиняет путь до «ага-момента» (лишние поля, туры, подтверждения), — убирается.

05  Development Phases

Четыре фазы разработки

Последовательность, а не всё сразу. Каждая фаза заканчивается проверяемым результатом.
PHASE 1 · FOUNDATION

Фундамент ✓ готово

Project setup (Next.js/TS), БД (Supabase + RLS), Authentication (NextAuth + 2FA + passkeys), Design System (токены), Basic Layout (shell: sidebar+topnav).

PHASE 2 · CORE PRODUCT

Ядро продукта ✓ в основном готово

Dashboard, AI Chat (стриминг), Agent System (20 директоров), History, Profile. Плюс бонус: генерация стратегий, совет с голосованием.

PHASE 3 · MONETIZATION

Монетизация ↻ последняя миля

Pricing (есть), Checkout (LemonSqueezy — доделать поток оплаты), Subscription (webhook есть), Usage Limits (серверные, есть: Free=3 проекта → 402).

PHASE 4 · IMPROVEMENT

Улучшения ↻ к запуску / после

Analytics (PostHog-события), Feedback (виджет + 👍/👎 на ответах), Notifications (email транзакционные), Optimization (кэш AI-ответов, скорость).

08  AI MVP Architecture

Какие AI-агенты нужны сначала

Для проверки гипотезы достаточно 3 сильных агентов (не 20). У Vertlix они уже есть — вот ядро для MVP-фокуса.

💼 Business Analyst / CFO

PurposeАнализ жизнеспособности, unit-экономика, финансовые риски.
Prompt«Ты — CFO мирового уровня. Оцени проект по числам, посчитай метрики, укажи 3 риска и как их закрыть. По-русски, конкретно, 7–12 предложений.»
Toolscalculate_metrics (LTV/CAC/MRR/ARR/burn/runway), get_project_data
OutputФинансовая оценка + метрики с формулами + список рисков.

📢 Marketing Expert / CMO

PurposeGTM-стратегия, позиционирование, каналы привлечения.
Prompt«Ты — CMO. Предложи позиционирование, 3 канала привлечения и первое сообщение для ЦА этого проекта.»
Toolssearch_web, generate_report
OutputGTM-план, воронка, месседжинг.

✅ Idea Validator / CEO-Стратег

PurposeБыстрая валидация идеи, «go / no-go», следующий шаг.
Prompt«Ты — CEO-стратег. Оцени идею: сильные/слабые стороны, стоит ли делать, и один самый важный следующий шаг.»
Toolsget_project_data, синтез мнений совета
OutputВердикт + обоснование + приоритетный next step.

Модель: Haiku для быстрых ответов, Opus для сложного анализа. Стриминг по токенам. Ответ всегда с обоснованием (не «чёрный ящик»).

13  First Users Strategy

Как получить первых пользователей

Не масштаб, а обучение. Первые пользователи — источник фидбека, а не выручки.

Первые 10 — вручную (Do things that don't scale)

Личные приглашения: знакомые основатели, чаты/сообщества предпринимателей, Indie Hackers. Персональный онбординг каждого, наблюдение за сессией, интервью «за что заплатил бы?». Цель — качество фидбека.

Первые 100 — публичный запуск

Product Hunt / Reddit (r/entrepreneur, r/startups) / профильные Telegram-каналы / LinkedIn-контент основателя. Бесплатный tier как крючок, «AI-совет директоров» как хук. Реферальная механика (пригласи → бонус-лимиты).

Первые 1000 — рост

Контент/SEO (шаблоны стратегий, разборы), партнёрства с бизнес-сообществами/акселераторами, платные каналы только после подтверждённой unit-экономики (LTV > 3×CAC). Кейсы первых пользователей как соц-доказательство.

16  Post-MVP Roadmap

После запуска

Строим следующее только после подтверждения спроса. Каждая версия — новый уровень ценности.
VERSION 1 · RETENTION & TEAMS

Команды и знания

Multi-Agent (совет-граф, делегирование) · Team (организации, роли, инвайты) · Knowledge Base (загрузка документов → RAG-ingestion; retrieval уже готов). Цель — удержание и expansion.
