# 📘 Документ 2 — Product Requirements Document (PRD)

## Обзор продукта

**Apex AI** — платформа для предпринимателей, которая заменяет дорогостоящих консультантов AI-командой из 8 специалистов (CEO, CFO, CMO, COO, CTO, Sales, Legal, Analyst). Пользователь описывает бизнес-идею — AI генерирует полную стратегию.

---

## 1. Главная страница (Landing Page)

### Цель
Конвертация посетителей в зарегистрированных пользователей.

### Секции
| Секция | Описание |
|---|---|
| Hero | Заголовок, подзаголовок, CTA "Начать бесплатно", анимация AI-совета |
| Как это работает | 3 шага: описать → AI анализирует → получить стратегию |
| AI-команда | Карточки 8 агентов с ролями и специализацией |
| Возможности | 6 ключевых фич с иконками |
| Цены | 3 тарифа: Free / Pro / Enterprise |
| Отзывы | Кейсы реальных пользователей |
| Footer | Ссылки, соцсети, правовые документы |

### Требования
- Время загрузки < 2 сек
- Mobile-first дизайн
- SEO-оптимизация (meta, OG, structured data)
- Конверсия CTA отслеживается через analytics

## 2. Авторизация

### Экраны
- **Регистрация** — email + пароль, или OAuth (Google, GitHub)
- **Вход** — email + пароль, Remember me, Forgot password
- **Восстановление пароля** — email → ссылка → новый пароль
- **Подтверждение email** — одноразовый код 6 цифр

### Требования
- JWT access token (15 мин) + refresh token (30 дней)
- Защита от brute-force (rate limiting: 5 попыток / 15 мин)
- 2FA опционально (TOTP)
- Сессии управляются в личном кабинете

## 4. Создание проекта

### Шаги (3-step wizard)

**Шаг 1 — Описание**
- Название проекта (required)
- Описание бизнес-идеи (min 20 символов, required)

**Шаг 2 — Параметры**
- Индустрия (выпадающий список, 15 вариантов)
- Стадия (идея / планирование / MVP / запущен)

**Шаг 3 — Цели**
- Цели (мультивыбор): привлечь инвестиции, запустить быстро, найти PMF, масштабировать
- Целевая выручка (опционально)
- Таймфрейм (6 / 12 / 18 / 24 месяца)

### После создания
- Показывается экран "AI команда работает" с прогресс-баром
- Real-time обновления через WebSocket / SSE
- По завершении — редирект на страницу проекта

---

## 5. Работа AI-команды

### Процесс
1. Пользователь создаёт проект
2. Задача ставится в очередь (Bull/Redis)
3. Параллельно запускаются 8 AI-агентов
4. CEO агрегирует ответы
5. Генерируется финальный отчёт

### Агенты и их зоны ответственности
| Агент | Зона |
|---|---|
| CEO | Стратегия, видение, приоритеты |
| CFO | Финансовая модель, юнит-экономика |
| CMO | Маркетинговая стратегия, каналы |
| COO | Операции, процессы, масштабирование |
| CTO | Технологии, архитектура, стек |
| Sales | GTM-стратегия, ICP, воронка |
| Legal | Юридические риски, структура |
| Analyst | Рынок, конкуренты, TAM/SAM/SOM |

### Статусы проекта
`queued` → `processing` → `complete` / `failed`

### Содержание отчёта (8 разделов)
1. Executive Summary
2. Financial Model
3. Market Analysis
4. Marketing Strategy
5. Operations Plan
6. Technology Stack

### Ограничения по тарифам
| Тариф | Отчётов/мес |
|---|---|
| Free | 3 |
| Pro | Unlimited |
| Enterprise | Unlimited + white-label |

## 7. Подписка (Billing)

### Тарифы
| | Free | Pro | Enterprise |
|---|---|---|---|
| Цена | $0 | $49/мес | $199/мес |
| Проектов | 3 | Unlimited | Unlimited |
| Отчётов | 3/мес | Unlimited | Unlimited |
| Экспорт PDF | ✓ | ✓ | ✓ |
| White-label | ✗ | ✗ | ✓ |
| API доступ | ✗ | ✗ | ✓ |
| Приоритет | Низкий | Высокий | Наивысший |

### Платёжный поток
1. Выбор тарифа → Stripe Checkout
2. Успешная оплата → webhook → обновление подписки в БД
3. Рекуррентное списание каждый месяц
4. Уведомление за 3 дня до списания
5. При отмене — доступ до конца оплаченного периода

## 12. Уведомления

### Типы
- Анализ завершён
- Новые инсайты доступны
