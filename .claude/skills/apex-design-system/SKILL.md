# Apex AI — Дизайн-система

Философия: **интерфейс исчезает, остаётся информация.** Красота = результат
ясности. Никакого неона, cyberpunk, дешёвых градиентов, тяжёлых glow.
Эталон качества: Stripe · Linear · Vercel · OpenAI · Apple.

## Токены (использовать ВСЕГДА, не изобретать новые)

### Цвет
- Фон: `#05060A` (страница), поверхности `rgba(255,255,255,0.03)`
- Рамки (hairline): `rgba(255,255,255,0.07)`, hover → `rgba(255,255,255,0.13)`
- Текст: primary `#E5E7EB`, secondary `rgba(255,255,255,0.5)`, muted `rgba(255,255,255,0.3)`
- **Единственный акцент**: индиго `#6366f1` / `#4f46e5`. Violet `#8b5cf6` — вторичный.
- Семантика (отдельно от акцента): success `#10b981`, warning `#f59e0b`, danger `#ef4444`
- В одной секции НЕ смешивать больше 1 акцента + семантику. Мульти-цвет допустим
  только для агентов-персонажей (у каждого агента свой цвет — это оправдано).

### Спейсинг — сетка 8px
Разрешённые значения: `4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 96`. Контент max-width `1200px`.

### Радиусы (согласованные, не мешать)
- Иконки/чипы: `10px` · кнопки/инпуты: `12px` · карточки: `16px` · крупные панели: `22px`

### Тени (матовые, нейтральные — НЕ цветные glow)
```
0 1px 2px rgba(0,0,0,0.4), 0 8px 32px rgba(0,0,0,0.28), inset 0 1px 0 rgba(255,255,255,0.045)
```
Цвет в тенях — только очень слабый ambient (`rgba(color,0.1)` максимум).

### Типографика
- Заголовки: `clamp()`, `font-weight: 800`, `letter-spacing: -0.02em`, `text-wrap: balance`
- Тело: `line-height: 1.6–1.75`, длина строки ~65 символов
- Uppercase-лейблы: `letter-spacing: 0.14em`, размер 10–11px

## Готовые классы (в globals.css)
`.surface-card`, `.surface-card-hover`, `.hairline`, `.text-balance` — использовать их
вместо дублирования стилей. Focus-states и `prefers-reduced-motion` уже глобальны.

## Правила компонентов
- **Кнопка primary**: индиго-градиент, `inset 0 1px 0 rgba(255,255,255,0.16)`, hover `-translate-y-px` + мягкая тень. Большая зона клика (h ≥ 44px — Fitts's Law).
- **Кнопка secondary**: ghost, hairline-рамка, hover высветляет рамку.
- **Карточка**: hairline-рамка + `surface-card` тень + hover-подъём 2px. Ничего плоского.
- **Инпут**: фон `rgba(255,255,255,0.035)`, focus — рамка индиго `rgba(99,102,241,0.5)`.

## Чек-лист перед сдачей любой секции
1. Один акцент? Радиусы из набора? Спейсинг кратен 8?
2. Hairline-рамки, а не цветные glow?
3. Заголовок отвечает на ОДИН вопрос секции (IA)?
4. Есть focus-state, контраст ≥ WCAG AA, кнопки ≥ 44px?
5. Работает на mobile без горизонтального скролла?
6. `npx tsc --noEmit` и `npm run build` — зелёные.

## Анти-паттерны (запрещено)
❌ неоновые рамки ❌ огромные размытые круги ❌ мульти-акцент в одной секции
❌ смешанные радиусы ❌ мелкий текст (<12px в body) ❌ плотные абзацы
❌ тяжёлый glassmorphism ❌ резкие движения
