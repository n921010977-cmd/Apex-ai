# Vertlix — адаптивность и доступность

## Брейкпоинты (контракт проекта)

| Ширина | Раскладка |
|---|---|
| < 640 | одна колонка, стек |
| 640–1023 | 2 колонки для компактных карточек |
| 1024–1279 | hero становится двухколоночным (текст + визуал) |
| ≥ 1280 | сложные абсолютные композиции разрешены |
| ≥ 1800 | контейнер расширяется до 1560px |

## Главное правило: перекомпоновать, а не сжимать

Сложную десктопную сцену **нельзя** просто масштабировать вниз — текст
становится нечитаемым. Ниже 1280 абсолютная композиция переводится в grid,
где главная панель идёт первой, а карточки-спутники укладываются под ней.

```css
/* mobile/tablet — поток */
.stage { display: grid; grid-template-columns: 1fr 1fr; gap: 12px; }
.stage-main { grid-column: 1 / -1; }

/* desktop — сцена */
@media (min-width: 1280px) {
  .stage { display: block; width: 700px; height: 508px;
           transform: scale(var(--stage-scale, 0.88)); }
  .stage > * { position: absolute; }
}
```

Две ловушки, на которых уже обжигались:

- **Порядок DOM определяет мобильный grid.** Две «половинчатые» карточки
  должны идти в разметке подряд, иначе в сетке появится дыра. Порядок
  появления задавать через `delay`, а не через перестановку разметки.
- **`transform: scale()` не меняет размер layout-бокса.** Родителю нужен
  `flex: 1 1 0; min-width: 0`, иначе «визуально влезло» ≠ «не распирает строку».

## Доступность (обязательный минимум)

- Контраст текста ≥ WCAG AA; вторичный текст не светлее `rgba(255,255,255,0.35)`
  на основном фоне для смысловой (не декоративной) информации
- Интерактив ≥ 44px по высоте, видимый `:focus-visible` (глобальный уже есть)
- Семантика: `<section>`, `<h1>`, списки — списками; декор — `aria-hidden`
- Меняющийся статус — `aria-live="polite"`
- `prefers-reduced-motion` в globals.css глушит анимации глобально — отдельные
  guard-ы в компонентах не нужны, но и `!important`-анимации добавлять нельзя

## Обязательная проверка перед сдачей UI

```bash
npx tsc --noEmit && npm run build
```

Затем прогон по вьюпортам (Playwright ставится глобально,
`NODE_PATH=/opt/node22/lib/node_modules`, Chromium `/opt/pw-browsers/chromium`):

**1920 · 1440 · 834 (tablet) · 430 · 390**

На каждом — скриншот + проверка переполнения:

```js
await p.evaluate(() => ({
  docW: document.documentElement.scrollWidth, winW: window.innerWidth
})); // docW > winW → горизонтальный скролл, чинить
```

Скриншот обязательно посмотреть глазами: отсутствие overflow не означает,
что карточки не перекрывают текст и ничего не обрезано.

## Анти-паттерны

❌ `scale()` десктопной сцены вместо перекомпоновки
❌ фиксированные ширины без `max-width: 100%`
❌ скрытие важного контента на мобильном вместо переноса
❌ горизонтальный скролл страницы
❌ «проверил только на своём экране»
