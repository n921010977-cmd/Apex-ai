# Apex AI — Анимации и движение

Принцип: **каждая анимация решает задачу** (направляет взгляд, даёт обратную
связь, объясняет переход). Никакого движения ради движения. Cдержанно, дорого,
плавно — как Apple keynote, а не как гейминг.

## Стек
- **Framer Motion** — для DOM: появление, hover, stagger, layout-переходы.
- **Canvas 2D + requestAnimationFrame** — для тяжёлых сцен с частицами
  (three/gsap НЕ установлены). Пример-эталон: `HeroCinematic.tsx`.

## Стандартные easing (использовать эти, не изобретать)
- Вход элементов: `[0.22, 1, 0.36, 1]` (ease-out-quint) — основной
- Пружина / «снап»: `[0.34, 1.56, 0.64, 1]` или `type: "spring", stiffness: 260, damping: 20`
- Симметричные переходы: `easeInOut`
- Count-up чисел: `1 - Math.pow(1 - t, 3)` (ease-out-cubic)

## Тайминги (согласованные)
- Hover / микро: `0.15–0.22s`
- Появление элемента: `0.5–0.7s`
- Stagger между детьми: `0.06–0.11s`
- Заполнение баров/колец: `1.3–1.5s`
- Крупные сцены (fusion, morph): фазы по `0.6–2.8s`

## Паттерны (переиспользовать)
- **Fade-up**: `initial={{opacity:0, y:20}} whileInView={{opacity:1, y:0}} viewport={{once:true, margin:"-60px"}}`
- **Stagger-грид**: контейнер с `staggerChildren`, дети — fade-up.
- **Hover-левитация карточки**: `whileHover={{y:-8}}` + пружина.
- **Count-up**: rAF + `useInView(once:true)`, парсить префикс/суффикс ("$140M+", "4.9/5").
- **Draw-in линии**: SVG `stroke-dashoffset` от длины к 0.
- **Marquee**: два ряда, встречное направление, пауза на hover, дублировать массив ×2.
- **Toggle-пилюля**: `layoutId` + spring для скольжения.

## Производительность (обязательно)
- Частицы: **спрайт-блиттинг** закешированных радиальных градиентов (`drawImage`),
  НЕ `shadowBlur` в цикле по каждой частице.
- Canvas: `devicePixelRatio` (clamp до 2), `ResizeObserver`, `ctx.setTransform(DPR...)`.
- `globalCompositeOperation = "lighter"` для энергетического свечения.
- Всегда `cancelAnimationFrame` + `ro.disconnect()` в cleanup.
- Цель — 60fps. Если сцена тяжёлая, снижать число частиц, а не качество кадра.

## Доступность (обязательно)
- Каждая авто-анимация должна иметь ветку `prefers-reduced-motion: reduce`
  (статичное финальное состояние). Проверять `window.matchMedia`.

## Анти-паттерны
❌ резкие/дёрганые движения ❌ бесконечный крутящийся glow ❌ лаги
❌ анимация всего сразу ❌ `shadowBlur` на сотнях частиц ❌ движение без цели
