# VERTLIX — дизайн-система

Продукт: платформа, где 20 AI-директоров разбирают бизнес-идею и выдают
стратегию с планом на 90 дней. Сайт должен читаться как **серьёзная
технологическая компания**, а не как AI-шаблон.

## Десять принципов (в порядке приоритета)

1. Продукт важнее декора.
2. Ясность важнее сложности.
3. Человеческая композиция важнее симметричной сетки одинаковых карточек.
4. Сдержанное движение важнее обилия анимаций.
5. Сильная типографика важнее лишней графики.
6. Реальный UI продукта важнее «футуристичных» иллюстраций.
7. Консистентность важнее новизны.
8. Производительность важнее визуальных трюков.
9. Доступность важнее эффектов.
10. Конверсия через ясность, а не через манипуляцию.

## Бренд и цвет (кратко; полностью — apex-design-system)

Фон `#05060A`–`#05060B`. Единственный акцент — пурпур `#7C3AED` / `#6D28D9`,
светлый шаг `#A78BFA`. Вторичный — indigo/blue `#4F46E5` / `#3B82F6`.
Подсветка — cyan `#22D3EE`. Положительное состояние — mint `#34D399`.

**В одной секции — один акцент плюс семантика.** Четыре карточки с четырьмя
разными светящимися иконками (magenta/blue/cyan/green) — это анти-паттерн,
он сейчас есть в FeaturesSection и подлежит унификации.

Мульти-цвет оправдан только там, где цвет несёт смысл: у каждого из 20 агентов
свой цвет — это идентификация, а не украшение.

## Что делает сайт «сгенерированным» — и чего не делать

❌ всё одинакового визуального веса ❌ симметричная сетка одинаковых карточек
❌ светится каждый элемент ❌ парит каждая карточка ❌ анимация в каждой секции
❌ градиент на всём подряд ❌ равномерные отступы между всеми блоками

Вместо этого: одна доминанта на экран, разные размеры и глубины, намеренная
асимметрия, осмысленный (неравномерный) вертикальный ритм.

## Честность контента — жёсткое правило

**Никогда не выдумывать**: логотипы клиентов, отзывы, число пользователей,
выручку, награды, партнёрства, кейсы, «2 300+ основателей», «4.9/5».

Можно: разбор одной показательной идеи с пометкой «sample», реальные
возможности продукта, реальные лимиты тарифов. Если данных нет — секция либо
переписывается под то, что есть, либо не существует. Пустой плейсхолдер
помечается как плейсхолдер явно.

## Порядок работы над визуалом

1. Прочитать профильный скилл из карты выше.
2. Сделать изменение, опираясь на токены, а не на литералы.
3. `npx tsc --noEmit && npm run build`.
4. `npm run qa:design` — 7 брейкпоинтов, overflow, контраст, axe.
5. **Посмотреть скриншоты глазами** — скрипт ловит механику, не композицию.

## Открытые долги (актуально на момент написания)

- 1410 инлайновых `fontSize` на 37 значений; 542 из них мельче 12px
- 26 нарушений контраста WCAG AA (в основном футер, `text-white/25…/45`)
- `prefers-reduced-motion` не достаёт до Framer Motion — нужен `MotionConfig`
- 4 сырых `<img>` мимо `next/image`
- eslint: setState внутри эффектов (риск для INP)
- главная 10 752px, между секциями двойные отступы по ~200px
