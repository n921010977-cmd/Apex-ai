# Apex AI — Графика и визуализации

## Важно: чем я реально рисую
В этой среде **нет генератора фотореалистичных картинок** (типа Midjourney/DALL·E).
Я создаю визуал кодом — и это даёт резкие, масштабируемые, анимируемые,
theme-aware результаты:
- **Inline SVG** — иконки, лого, абстрактные «3D» формы, диаграммы
- **Canvas 2D + rAF** — частицы, генеративные сцены (см. `HeroCinematic.tsx`)
- **CSS** — градиентные меши, свечения, glassmorphism, mesh-фоны

Если нужна настоящая растровая генерация — это делается через отдельный
image-gen MCP/API (можно подключить); скажи, и я объясню как.

## Иконки
- Стиль: **outline, stroke 1.5–2px**, оптический размер 24, скруглённые концы.
- Один набор на весь проект (сейчас — lucide-react). Не мешать стили.
- Цвет — `currentColor` или акцент из дизайн-системы.

## «3D» / абстрактные визуалы (без Three.js)
- Frosted-glass ядро: слои `linear-gradient` + `backdrop-filter: blur` + hairline-рамка.
- Металлический блик: `inset 0 1px 0 rgba(255,255,255,0.2)` + верхний shimmer-градиент.
- Орбитальные кольца: SVG `<ellipse>` с разными `rotate()` для псевдо-3D наклона.
- Глубина — слоями и тенями, НЕ псевдо-3D трансформами наобум.

## Диаграммы и графики
- Перед любым чартом свериться со встроенным скилом **dataviz** (палитра, легенды, оси).
- Area chart: `strokeDashoffset` для draw-in, мягкая заливка градиентом, акцент на конечной точке.
- Gauge/ring: SVG arc + `stroke-dasharray` анимация, число — count-up.
- Sparkline: `<polyline>` из данных + точка на конце.
- `font-variant-numeric: tabular-nums` для колонок цифр.
- Сетка/оси — очень слабые (`rgba(255,255,255,0.06)`), данные — контрастные.

## Палитра для графики (из дизайн-системы)
indigo `#6366f1` · violet `#8b5cf6` · blue `#3b82f6` · cyan `#06b6d4` ·
emerald `#10b981` · amber `#f59e0b`. Приглушённые, не кислотные.

## Экспорт / артефакты
- Для standalone-визуала, который пользователь должен увидеть/сохранить —
  можно рендерить через инструмент Artifact (сначала загрузить скил artifact-design).
- SVG/Canvas — всё inline, self-contained (CSP блокирует внешние ресурсы в артефактах).
