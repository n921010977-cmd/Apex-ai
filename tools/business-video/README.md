# Генератор ролика «Как построить успешный бизнес?»

Вертикальный анимационный ролик (720×1280, 30 fps, ~76 с) в стиле
«мультяшный ведущий + всплывающие стикеры + пословные субтитры»:
белый фон с 3D-сеткой, персонаж снизу, крупные заголовки, которые
появляются по мере озвучки, жёлтые маркер-подсветки ключевых слов,
iOS-карточки и эмодзи-стикеры сверху.

Готовый ролик: `out/output.mp4`.

## Как устроено

| Файл | Назначение |
| --- | --- |
| `build.py` | Оркестратор: сценарий → TTS → тайминги слов → музыка → рендер → mux |
| `template.html` | Сцена. `window.seek(t)` детерминированно рисует кадр для времени `t` |
| `render.js` | Playwright/Chromium: прогоняет `seek(t)` по кадрам и стримит JPEG прямо в ffmpeg |
| `assets/fonts/` | Montserrat (заголовки) и Inter (карточки), с кириллицей |

Сценарий и раскадровка лежат в `build.py` (список `SEGS`): каждый сегмент —
одна TTS-фраза + разбивка субтитров на фразы с подсветками + спецификация
сцены (стикер / карточка-цитата / чек-лист / цикл / сравнение / формула) +
поза персонажа. Тайминги слов оцениваются пропорционально длине слова внутри
измеренной длительности синтезированной фразы.

## Зависимости

- Python 3: `pip install piper-tts numpy`
- Голос Piper (не хранится в репо, ~60 МБ):
  [`voice-ru-irinia-medium.tar.gz`](https://github.com/rhasspy/piper/releases/download/v0.0.2/voice-ru-irinia-medium.tar.gz) —
  распаковать `ru-irinia-medium.onnx` + `.json` рядом с `build.py`
  (или указать путь через `--voice` / `PIPER_VOICE`)
- Node + Playwright (`npm i playwright`) с Chromium
- ffmpeg

## Сборка

```bash
python3 build.py            # всё сразу: TTS → аудио → кадры → out/output.mp4
python3 build.py --skip-render   # только аудио + тайминги
node render.js --preview 1.2,9,43.5   # PNG-стоп-кадры для проверки сцен
```

Фоновая музыка (тихий lo-fi пад + бас + хэты) синтезируется numpy прямо в
`build.py`, микшируется на −10 dB под голосом.
