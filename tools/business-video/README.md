# Генератор вертикальных бизнес-роликов

Вертикальные анимационные ролики (720×1280, 30 fps) в стиле «мультяшный
ведущий + всплывающие стикеры + пословные субтитры»: белый фон с 3D-сеткой,
персонаж снизу, крупные заголовки, которые появляются по мере озвучки,
маркер-подсветки ключевых слов, iOS-карточки и эмодзи-стикеры сверху.

Движок один, но каждый ролик — свой **профиль**: свой сценарий, свой
персонаж (внешность, палитра сцены) и свои настройки голоса (темп, тембр,
паузы). Так разные видео не выглядят и не звучат клоном друг друга.

| Профиль | Ролик | Персонаж | Голос |
| --- | --- | --- | --- |
| `business` | «Как построить успешный бизнес?» — `out/output.mp4` | бородатый парень в бежевой фланели, жёлто-синяя мотивационная палитра | энергичный, обычный темп |
| `bankruptcy` | «Как не обанкротить свой бизнес?» — `out/bankruptcy/output.mp4` | зрелый консультант в очках, тёмно-синий пиджак с галстуком, без бороды; тревожно-янтарная палитра | медленнее, ниже (питч-шифт −2 полутона), весомее паузы |

## Как устроено

| Файл | Назначение |
| --- | --- |
| `build.py` | Оркестратор: сценарий профиля → TTS (+питч-шифт) → тайминги слов → музыка → рендер → mux |
| `scripts/<profile>.py` | Сценарий (`SEGS`), внешность персонажа и палитра (`PROFILE`), настройки голоса (`VOICE`) |
| `template.html` | Сцена. `window.seek(t)` детерминированно рисует кадр для времени `t`; `applyProfile()` красит персонажа и палитру под текущий профиль |
| `render.js` | Playwright/Chromium: прогоняет `seek(t)` по кадрам и стримит JPEG прямо в ffmpeg |
| `assets/fonts/` | Montserrat (заголовки) и Inter (карточки), с кириллицей |

Сценарий и раскадровка каждого профиля лежат в `scripts/<profile>.py`
(список `SEGS`): каждый сегмент — одна TTS-фраза + разбивка субтитров на
фразы с подсветками + спецификация сцены (стикер / карточка-цитата /
чек-лист / цикл / сравнение / формула-цепочка / duo-сравнение) + поза
персонажа. Тайминги слов оцениваются пропорционально длине слова внутри
измеренной длительности синтезированной фразы; спец-ключи `chain_words` /
`cycle_words` / `rows_words` синхронизируют появление элементов сцены с
конкретным произносимым словом.

`PROFILE` в каждом скрипте — это и цвета сцены (`accent`/`danger`/`safe`/
`highlight`/`gridColor`), и внешность персонажа (`skin`, `hair`,
`hairStyle: 'tousled'|'short'`, `beard: bool`, `glasses: bool`, `tie`,
`grey` — седина на висках, `shirt`/`tee` — одежда). Пустой `PROFILE = {}`
(как у `business`) означает «внешний вид и палитра по умолчанию» — это
гарантирует, что уже отрендеренный и закоммиченный ролик не изменится
при рефакторинге движка.

`VOICE` управляет параметрами Piper (`length_scale`, `noise_scale`,
`noise_w_scale`, `sentence_silence`) и опциональным питч-шифтом
(`pitch_semitones`, реализован через ffmpeg `rubberband` после синтеза —
сохраняет длительность, меняет только тембр).

## Зависимости

- Python 3: `pip install piper-tts numpy`
- Голос Piper (не хранится в репо, ~60 МБ):
  [`voice-ru-irinia-medium.tar.gz`](https://github.com/rhasspy/piper/releases/download/v0.0.2/voice-ru-irinia-medium.tar.gz) —
  распаковать `ru-irinia-medium.onnx` + `.json` рядом с `build.py`
  (или указать путь через `--voice` / `PIPER_VOICE`)
- Node + Playwright (`npm i playwright`) с Chromium
- ffmpeg собран с фильтром `rubberband` (для питч-шифта; без него просто не задавайте `pitch_semitones`)

## Сборка

```bash
python3 build.py --profile business       # -> out/output.mp4
python3 build.py --profile bankruptcy     # -> out/bankruptcy/output.mp4

python3 build.py --profile bankruptcy --skip-render   # только аудио + тайминги
node render.js --out out/bankruptcy --preview 1.2,9,43.5   # PNG-стоп-кадры для проверки сцен
```

Фоновая музыка (тихий пад + бас + хэты) синтезируется numpy прямо в
`build.py` и микшируется на −10 dB под голосом; `PROFILE.musicMood =
'serious'` переключает её на более медленный тёмный вариант (использует
`bankruptcy`).

## Новый профиль

1. Скопировать `scripts/business.py` в `scripts/<name>.py`, заменить
   `SEGS` на новый сценарий, подобрать `PROFILE` (внешность + палитра) и
   `VOICE` (темп/тембр/паузы).
2. `python3 build.py --profile <name>` — соберёт `out/<name>/output.mp4`.
